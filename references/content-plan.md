# 内容规划

仅在规划或改写 PPT 内容时阅读。

先写一份逐页提纲，每页记录主题、面试官应看到的证据、可见文字、讲稿摘要、图片或流程图需求。不要把现有成稿的 13 页当作固定结构。

根据岗位 JD 选择排序与比重。AI 应用岗位可突出 Agent 编排、工具接入、检索与评测；后端或平台岗位可突出接口、身份、并发、治理和可观测性；流程或企业 IT 岗位可突出业务接入、跨系统流程、权限与效果评估。以实际 JD 为准，岗位名称相同也可能关注不同能力。

常见页面可从封面、个人简介、核心项目、项目流程、竞赛与论文、个人总结、结束页中选择。一个项目通常先讲背景、个人工作和结果，再放流程图。流程图应包含必要的节点、条件和回环，文字只覆盖关键动作。仅凭材料无法确认的步骤不要补造。

页面文字以扫读为目标。讲稿用第一人称自然表达，说明“为什么做、我做了什么、怎么验证”。对可跳过的流程图，备注中先写一句简述，再写追问时的详细说法。若面试时长未知，不强制给每页标秒数。
